While immense insight can be gain from linear analysis tools, such as those developed within the [WEC co-design project](/projects/6_project), there is also value in the ability to fully consider the nonlinear behavior of a real system.
To that end, [WecOptTool](https://sandialabs.github.io/WecOptTool/index.html) utilizes a pseudo-spectral to efficiently perform simulation/optimization of wave energy converters (WECs).
The tool was first conceptualized in Giorgio Bacelli's PhD thesis {% cite Bacelli:2014aa Bacelli:2014ab %}, and then developed as an open-source tool by Sandia {% cite Coe:2020aa %}.
WecOptTool has been applied extensively to support external developers {% cite Gaebele:2023wf %} and research projects including the [Pioneer WEC](/projects/1_project) {% cite Grasberger:2025ad Devin:2024aa Coe:2024aa %}, the [WaveBot](/projects/8_project) {% cite Grasberger:2023aa Michelen-Strofer:2023aa %}, and the [LUPA](https://pmec-osu.github.io/LUPA/) {% cite Michelen-Strofer:2023ab %}
